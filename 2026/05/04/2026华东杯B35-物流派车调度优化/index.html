第二十八届华东杯大学生数学建模邀请赛 B 题（Team B35，三等奖）。本文针对医药物流企业的派车调度与运单聚类问题，构建了"数据清洗 → 全成本建模 → 时空聚类 → ALNS 自适应大邻域搜索"的四阶段求解体系。核心创新：ST-DBSCAN + ALNS 混合算法在 18.5 万运单、5 维多目标约束下，综合得分提升 75%，装载率从 21.7% 提升至 50.5%。

一、问题重述与分析

1.1 问题背景

某医药物流企业总部位于南通市崇川区，承担药品从多个仓库到各级医院的冷链运输任务。企业运营三种型号车队（4.2M / 7.6M / 9.6M），积累了三个自然月（2018 年 8 月—11 月）的运营数据：

  • 派车单数据（~1,000 条）：包含车型、路线顺序、预计到货时间、托盘数
  • 运单数据（~185,000 条）：包含物流单号、收货地址、温度类型、容积当量、调度时间

运单温度类型覆盖：冷链、常温、贵冷、贵重、麻精，其中冷链药品对运输车辆的温度属性有严格匹配要求。

当前痛点：派车方案存在装载率低、车辆数与货物量不匹配、温度属性混装等问题，亟需系统性的优化建模。

1.2 三个子问题

问题 任务描述 数据规模 核心方法
问题一 核算当前固定方案的运输成本，分析成本结构 ~1,000 条 全成本模型 + 高德 API 距离矩阵
问题二 基于时空特征优化派车方案，降低成本 ~1,000 条 ST-DBSCAN + 熵权法 + 模拟退火
问题三 对全量运单进行聚类分析，优化调度方案 ~185,000 条 ST-DBSCAN (cKDTree 加速) + AHP + ALNS

四、问题二：派车方案优化

4.1 派车单时空聚类 (ST-DBSCAN)

在优化之前，先对派车单进行时空聚类，识别具有"协同配送潜力"的订单群体。

样本特征向量：

Pi=(xi,yi,ti)P_i = (x_i, y_i, t_i) Pi​=(xi​,yi​,ti​)

其中 (xi,yi)(x_i, y_i)(xi​,yi​) 为收货地址经纬度，tit_iti​ 为到货天数（相对于最早日期的偏移）。

时空邻域定义：

Nε(Pi)={Pj∈D∣dspatial(Pi,Pj)≤εs∧∣ti−tj∣≤εt}(2)N_{\varepsilon}(P_i) = \{P_j \in D \mid d_{spatial}(P_i, P_j) \leq \varepsilon_s \land |t_i - t_j| \leq \varepsilon_t\} \tag{2} Nε​(Pi​)={Pj​∈D∣dspatial​(Pi​,Pj​)≤εs​∧∣ti​−tj​∣≤εt​}(2)

4.5 鲁棒性检验

实际运输中行驶时间受交通路况影响，存在不确定性。采用蒙特卡洛扰动框架检验方案的准时率：

  • 对每条道路的行驶时间施加 Uniform(1.0,ρ)\text{Uniform}(1.0, \rho)Uniform(1.0,ρ) 的随机扰动
  • ρ\rhoρ 从 1.0 到 1.5 扫描，每个 ρ\rhoρ 模拟 100 次
  • 装卸作业时间固定为 2h

在 1.3 倍扰动范围内，准时率仍保持 > 85%，方案具有良好的抗干扰能力。

5.2 ST-DBSCAN 大规模加速

标准 ST-DBSCAN 的 O(n2)O(n^2)O(n2) 复杂度无法处理 53 万行数据。三层加速策略：

第一层：唯一键压缩

对经纬度（保留 6 位小数，精度 ~0.1m）和时间（保留 3 位小数）进行精度截断，将原始 53 万行压缩为 ~5 万个唯一时空点。复杂度降为 O(Nuniquelog⁡Nunique)O(N_{unique} \log N_{unique})O(Nunique​logNunique​)。

第二层：cKDTree 空间索引

第三层：CSR 稀疏图 + BFS 扩展

将所有有效时空边存储为 Compressed Sparse Row (CSR) 格式邻接表，再进行 BFS 广度优先搜索扩展聚类。CSR 将稀疏图的存储从稠密矩阵的 O(n2)O(n^2)O(n2) 压缩至 O(n+m)O(n + m)O(n+m)（mmm 为边数），内存占用降低 97%。

六、模型评价

6.1 优点

  1. 分层架构合理：数据清洗 → 聚类 → 路径优化，各层职责清晰，可独立调优
  2. 规模可扩展：cKDTree + CSR 稀疏图的三层加速使 50 万+ 数据的时空聚类在数分钟内完成
  3. 多目标科学量化：AHP 一致性检验通过 (CR=0.015)，温度适配权重体现了医药物流的核心价值观
  4. ALNS 自适应强：算子权重动态更新，不同簇的数据特征自适配不同的破坏/修复策略
  5. 实时监控：HTML 仪表板 + Chart.js 实现优化过程的实时可视化，便于调参
  6. 三层鲁棒性保障：蒙特卡洛扰动检验准时率 + 温度适配硬约束 + 超载惩罚机制

6.2 缺点与改进方向

  1. 准时率简化为常数（0.92），未来可接入真实的时间窗口计算和交通拥堵预测
  2. 簇间路线独立优化，相邻簇的配送路线可能有合并空间，可用 2-opt 或 LKH 进行后处理
  3. 农药、肥料等部分化工品在清洗时被剔除，这些零散订单可能有业务价值
  4. 仅用了 AHP 主观赋权，可引入熵权法或 CRITIC 进行客观权重修正，形成主客观组合赋权

6.3 模型推广

本模型的"聚类 + 优化"双阶段框架可推广至：

  • 生鲜冷链配送：替换温度约束为保鲜窗口
  • 快递末端揽派：替换装载率目标为派送时效
  • 危险品运输：替换温度匹配为隔离约束
